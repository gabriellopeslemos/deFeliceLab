# De Felice Lab — website

A static site (plain HTML/CSS/JS, no build step, no dependencies) for the De Felice Lab
research program. The hero section uses a WebGL fabric-ripple background rendered on a
`<canvas>`, sampling `assets/logosDeFeliceLab/textureBackground.png`.

## Running locally

The site **must be served over HTTP** — do not open `index.html` directly as a `file://`
URL. The hero's WebGL shader loads a texture image, and browsers block that texture read
under `file://` (the canvas becomes "tainted" and the hero falls back to a flat navy
colour). A local HTTP server fixes this.

Pick whichever you have installed. Run it from the project root (`E:\Repositorios\lab`):

### Python 3

```bash
python -m http.server 8777
```

### Node.js

```bash
npx serve -l 8777
# or
npx http-server -p 8777
```

### PHP

```bash
php -S localhost:8777
```

Then open:

```
http://localhost:8777/index.html
```

Other pages:

- `http://localhost:8777/study.html` — studies / recruitment page

## Requirements

- Any static file server (Python, Node, PHP, or similar) — see options above.
- A modern browser with **WebGL** enabled (Chrome, Edge, Firefox, Safari). Without WebGL,
  the hero gracefully falls back to a solid navy background.
- An internet connection on first load — fonts are pulled from Google Fonts. Everything
  else (styles, scripts, images) is local.

## Updating publications (ORCID)

The publications section (`#pubs` in `index.html`) is populated at runtime by
`assets/pubs.js`, which fetches `assets/publications.json`. That JSON file is
generated locally by a Python script that queries the ORCID public API — it is not
regenerated automatically, so re-run it whenever the lab publishes something new.

### One-time setup

1. Create/use an ORCID account at https://orcid.org and register an app under
   **Developer Tools** (https://orcid.org/developer-tools). Any redirect URI works
   (e.g. the site's URL) — it isn't used by the read-only flow this script uses.
2. Copy `.env.example` to `.env` and fill in:
   - `ORCID_CLIENT_ID` / `ORCID_CLIENT_SECRET` — from the app you just registered.
   - `ORCID_IDS` — comma-separated ORCID iD(s) (format `0000-0000-0000-0000`) of the
     lab's researchers whose publications should appear. Look one up at
     https://orcid.org/orcid-search if needed.
3. `.env` is git-ignored — never commit it.

### Running the script

```bash
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r scripts/requirements.txt
python scripts/fetch_orcid_publications.py
```

This writes `assets/publications.json`. Commit that file so the live site reflects
the update (there is no build step or CI pulling this automatically yet).

To add curated details ORCID doesn't provide (a topic tag, a full author byline, a
"why it matters" note, a citation count), edit `scripts/publications-overrides.json`
— keyed by DOI (lowercase) or, if a work has no DOI, its normalized lowercase title —
then re-run the script so the override gets merged in.

## Notes

- The hero WebGL background lives inline in `index.html` (a `<script>` before `</script>`
  near the end of the body) and is styled by the `.hero-canvas` / `.hero-scrim` rules in
  `assets/styles.css`. It was ported from `Hero Waves.dc.html`.
- Motion respects `prefers-reduced-motion`: with reduced motion enabled the hero paints a
  single static frame instead of the animated loop.
